# Cyberpunk

An original Nookdeck theme pack: **Neon** (magenta on black), **Acid** (green on black) and **Chrome** (light). **Auto** uses Chrome by day and Neon at night.

- Clipped tile corners, corner ticks, faint scanlines, upper-case labels and a mono font. The clock glitches for a moment every few seconds. The glitch stops in lite mode and when the phone asks for reduced motion.
- Designed for Nookdeck. It does not copy any game, film or brand.
- Font: [Share Tech Mono](https://github.com/google/fonts/tree/main/ofl/sharetechmono) (Latin subset, from Fontsource), SIL Open Font License 1.1, in [OFL-ShareTechMono.txt](OFL-ShareTechMono.txt).
