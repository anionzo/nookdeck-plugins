# Brutalist

An original Nookdeck theme pack: thick 3 px borders, hard offset shadows, flat clashing colours and oversized numbers. Variants: Yellow, Concrete, Riot. It does not copy any game, film, product or brand.

- Fonts: [Archivo Narrow](https://github.com/Omnibus-Type/ArchivoNarrow) Bold for labels (OFL, [OFL-ArchivoNarrow.txt](OFL-ArchivoNarrow.txt)), and [Archivo Black](https://github.com/Omnibus-Type/ArchivoBlack) by the Archivo Black Project Authors (Latin subset, from Fontsource). SIL Open Font License 1.1, see [OFL-ArchivoBlack-Regular.txt](OFL-ArchivoBlack-Regular.txt).
- Theme code and CSS: the same licence as this registry (see the repository LICENSE).
- CSS only, no scripts, no animation.
