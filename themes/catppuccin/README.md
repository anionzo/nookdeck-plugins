# Catppuccin

A Nookdeck theme pack of [Catppuccin](https://catppuccin.com): Latte (light), Frappé, Macchiato and Mocha (dark), with a choice of the 14 Catppuccin accents. Mauve is the default.

- Colours are the official Catppuccin palette (from [catppuccin/palette](https://github.com/catppuccin/palette)): base and crust for the background, surface0 for tiles, surface1 for borders, text for text, and green, yellow, red and blue for the state colours.
- Use **Auto** to follow the phone's light or dark setting: Latte by day, Mocha at night.
- This is a port by Nookdeck, not an official Catppuccin release. The name is used as a port only.
