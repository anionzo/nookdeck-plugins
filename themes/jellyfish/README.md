# JellyFish

A Nookdeck theme pack with one variant, a port of the [JellyFish](https://github.com/pawelborkar/vscode-jellyfish) VS Code theme by Pawel Borkar. It is dark only, so there is no Auto pair.

- Colours are copied from its theme file: the editor background and foreground, the tab, button and panel border colours, and the syntax colours for state and chart colours.
- Licence: Apache-2.0, Copyright 2021-23 Pawel Borkar. The text is in [LICENSE](LICENSE). Changes: the colours are used as Nookdeck theme values; no code from the original is included.
- A port by Nookdeck, not an official release.
