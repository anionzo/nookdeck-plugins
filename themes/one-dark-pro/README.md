# One Dark Pro

A Nookdeck theme pack of [One Dark Pro](https://github.com/Binaryify/OneDark-Pro) by Binaryify: One Dark Pro, Flat, Darker, Mix and Night Flat. All are dark, so there is no Auto pair.

- Colours are copied from the theme files in that repository: the editor background, foreground, panel border and list hover colour, plus the syntax colours for the accent, state colours and charts.
- Licence: MIT, Copyright (c) 2013-2022 Binaryify. The text is in [LICENSE](LICENSE).
- A port by Nookdeck, not an official release. One Dark Pro is itself based on Atom's One Dark syntax theme.
