# Blueprint

An original Nookdeck theme pack: a technical-drawing look with a fine grid, hairline tiles and corner ticks. Variants: Blueprint and Whiteprint. It does not copy any product or brand.

- Font: [IBM Plex Mono](https://github.com/IBM/plex) Regular and SemiBold (Latin subset, from Fontsource), SIL Open Font License 1.1, see [OFL-IBMPlexMono.txt](OFL-IBMPlexMono.txt).
- Theme code and CSS: the same licence as this registry (see the repository LICENSE).
- CSS only, no scripts, no animation.
