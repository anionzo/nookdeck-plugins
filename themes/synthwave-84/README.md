# SynthWave '84

A Nookdeck theme pack: **SynthWave '84** and **Midnight drive**, with five accent choices (pink, cyan, yellow, green, orange). It adds a sunset glow, a perspective grid, neon glow on the numbers, and a sun over a grid on the standby screen. No animation, so it is light on the phone.

- A port of [SynthWave '84](https://github.com/robb0wen/synthwave-vscode) by Robb Owen. The colours are copied from its theme file (editor and sidebar backgrounds, the pink, cyan, yellow, green and red accents).
- Licence: MIT, Copyright (c) 2019 Robb Owen. The text is in [LICENSE](LICENSE).
- Font: [Orbitron](https://github.com/theleagueof/orbitron) Bold (Latin subset, from Fontsource), SIL Open Font License 1.1, in [OFL-Orbitron.txt](OFL-Orbitron.txt).
- Not an official release of the original theme.
- CSS only: no scripts. Works in lite mode and with reduced motion.
