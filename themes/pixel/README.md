# Pixel

An original Nookdeck theme pack: stepped pixel borders, a dithered sheet and a chunky palette. Variants: Arcade and Handheld (four greens). The names are generic; the look does not copy any game, console or brand.

- Fonts: [Silkscreen](https://kottke.org/plus/type/silkscreen/) by Jason Kottke for labels (Latin subset, from Fontsource), SIL Open Font License 1.1, see [OFL-Silkscreen.txt](OFL-Silkscreen.txt), and [Press Start 2P](https://github.com/codeman38/PressStart2P) by Cody "CodeMan38" Boisclair (Latin subset, from Fontsource), SIL Open Font License 1.1, see [OFL-PressStart2P.txt](OFL-PressStart2P.txt).
- Theme code and CSS: the same licence as this registry (see the repository LICENSE).
- CSS only, no scripts, no animation.
