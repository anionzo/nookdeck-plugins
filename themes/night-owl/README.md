# Night Owl

A Nookdeck theme pack: **Night Owl** (dark) and **Light Owl** (light). Use **Auto** to follow the phone's light or dark setting: Light Owl by day, Night Owl at night.

- A port of [Night Owl](https://github.com/sdras/night-owl-vscode-theme) by Sarah Drasner. The colours are copied from its theme files: the editor, foreground, comment, terminal and gutter colours, plus the token colours for charts. The tile colour is Night Owl's active tab background.
