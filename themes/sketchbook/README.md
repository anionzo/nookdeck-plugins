# Sketchbook

An original Nookdeck theme pack: ruled paper, wobbly hand-drawn outlines and a marker highlight. Variants: Notebook and Chalkboard. It does not copy any product or brand.

- Font: [Caveat](https://github.com/googlefonts/caveat) Regular and Bold (Latin subset, from Fontsource), SIL Open Font License 1.1, see [OFL-Caveat.txt](OFL-Caveat.txt).
- `paper.png`: a 160 px noise grain generated for this pack, free to reuse under the same licence as the theme.
- Theme code and CSS: the same licence as this registry (see the repository LICENSE).
- No scripts, no animation.
