# Terminal

An original Nookdeck theme pack: a CRT phosphor look with scanlines, a soft glow, dashed ASCII-style tile borders and a blinking block cursor in the top bar. Variants: Green, Amber, Ice. It does not copy any game, film, product or brand.

- Font: [VT323](https://github.com/phoikoi/VT323) by Peter Hull (Latin subset, from Fontsource). SIL Open Font License 1.1, see [OFL-VT323-Regular.txt](OFL-VT323-Regular.txt).
- Theme code and CSS: the same licence as this registry (see the repository LICENSE).
- CSS only, no scripts. The cursor blink stops in lite mode and with reduced motion.
